# SQL Business Case Study - Retail Sales Analysis

## 📌 Project Overview

This project demonstrates SQL-based business analysis using a retail sales dataset. The objective is to answer real-world business questions by analysing sales, profit, quantity, regions, states, and product categories using MySQL.

---

## 🛠 Tools Used

- MySQL Workbench
- SQL

---

## 📊 SQL Concepts Covered

- Aggregate Functions
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- CASE Statements
- Subqueries
- Window Functions (RANK, DENSE_RANK, ROW_NUMBER)

---

## 📈 Business Questions Solved

- Total Sales
- Total Profit
- Total Quantity Sold
- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Top Performing States
- Sub-Category Analysis
- Profit Margin Analysis
- Discount Analysis
- Sales Ranking
